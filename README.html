Apresentação da disciplina

Identificação

  • Componente curricular: Linguagens de Programação e Banco de Dados
  • Curso: Tecnologia em Automação Industrial
  • Período: 2º semestre
  • Carga horária: 80 horas-aula
  • Organização: 20 unidades de 4 horas-aula
  • Modalidade: presencial
  • Tecnologias principais: Python e PostgreSQL

Ementa

  • Programação orientada a objetos;
  • Desenvolvimento de algoritmos;
  • Bancos de dados relacionais;
  • Modelagem de dados;
  • Manipulação de dados utilizando SQL;
  • Bancos de dados de séries temporais;
  • Aplicações em sistemas industriais de controle e automação.

Onde esta disciplina se encaixa?

A disciplina articula conhecimentos de:

  • Algoritmos de Programação;
  • Instrumentação Industrial;
  • Metrologia;
  • Análise de Circuitos Elétricos;
  • Automação Industrial;
  • Sistemas Supervisórios;
  • Redes Industriais;
  • Sistemas Embarcados.

O foco será transformar dados de sensores e equipamentos em informações úteis para a operação industrial.

Como vamos trabalhar

Metodologia

As aulas serão baseadas em:

  • Problemas de automação industrial;
  • Projetos práticos;
  • Simulações de sensores e equipamentos;
  • Desenvolvimento incremental de sistemas;
  • Testes e correção de falhas;
  • Trabalho individual e em equipe;
  • Demonstrações práticas.

Dinâmica de cada unidade

  1. Apresentação de um problema;
  2. Discussão de possíveis soluções;
  3. Introdução dos conceitos necessários;
  4. Desenvolvimento no laboratório;
  5. Testes com diferentes situações;
  6. Melhorias na solução;
  7. Demonstração ou entrega da atividade.

A teoria será apresentada como ferramenta para resolver problemas concretos.

Desenvolver aplicações em Python integradas a bancos de dados relacionais, aplicadas a problemas de monitoramento, aquisição e análise de dados em sistemas industriais de controle e automação.

Ao final da disciplina, você deverá ser capaz de:

  • Desenvolver algoritmos em Python;
  • Utilizar estruturas condicionais e de repetição;
  • Organizar dados em listas e dicionários;
  • Criar funções e módulos reutilizáveis;
  • Aplicar conceitos de programação orientada a objetos;
  • Simular sensores e dispositivos de aquisição de dados;
  • Modelar bancos de dados relacionais;
  • Criar tabelas e relacionamentos no PostgreSQL;
  • Executar consultas SQL;
  • Integrar aplicações Python com PostgreSQL;
  • Registrar leituras e alarmes;
  • Desenvolver uma solução aplicada a um problema industrial.

Unidade 15 — Geração automática de alarmes

Problema: o sistema deve gerar um alarme sempre que uma leitura ultrapassar os limites configurados.

Atividade prática

Ao registrar uma leitura, o sistema deverá:

  1. Consultar os limites do sensor;
  2. Comparar o valor medido;
  3. Classificar o estado;
  4. Registrar o alarme, se necessário;
  5. Associar o evento ao equipamento;
  6. Exibir uma mensagem ao operador.

Situações a considerar

  • Leitura normal;
  • Valor acima do limite;
  • Valor abaixo do limite;
  • Sensor sem resposta;
  • Valor inválido;
  • Falha de comunicação;
  • Equipamento desativado.
